# Source and licence notices

The repository retains published reference citations and notices required by
included components. Those notices are not manuscript author metadata.

- `supplementary/upstream/LICENSE`: MIT notice applying to the included upstream
  circuit/simulation source. This notice names an institutional copyright holder.
- `supplementary/study/third_party/LICENSE-Fiorini.txt`: MIT notice for the
  independently attributed interception-density formula implementation.
- `supplementary/vendor/LICENSE-pyldpc.txt` and the wheel's licence: BSD terms
  for the supplied historical decoder dependency.
- `overleaf/acm-source/` and the headers of the ACM class/bibliography style:
  original template source and licensing notices. The circuit regression fixture
  retains its own matching ACM support files.

Personal author information, private repository addresses and local-machine paths
are omitted from the repository edition. The required institutional notice and
external reference authors remain. No blanket replacement licence is imposed on
components with different existing terms. Dependency licences also apply when
those packages are installed.
